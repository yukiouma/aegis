# CRF Crate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `lib/crates/crf`, a Rust library that owns CRUD + version-scoped search over the Case Report Form aggregates (`CrfVersion`, `CrfForm`, `CrfItem`, `CrfOption`, `CrfUnit`, `DomainAnnotation`, `Annotation`) and exposes them through a new `apis::crf::CrfService` outbound port, backed by PostgreSQL.

**Architecture:** Ports-and-adapters DDD structure mirroring `lib/crates/domain-model` and `lib/crates/project`. Seven repository ports (`CrfVersionRepository`, `CrfFormRepository`, `CrfItemRepository`, `CrfOptionRepository`, `CrfUnitRepository`, `DomainAnnotationRepository`, `AnnotationRepository`) plus a narrow cross-crate `ProjectLookup` port live in `domain`. A single `CrfUsecase<V, F, I, O, U, Da, A, P>` is generic over all eight ports. A PostgreSQL adapter implements each port; a `ProjectLookupImpl` adapts `apis::project::ProjectService` to the domain `ProjectLookup`; an in-memory `CrfServiceImpl` adapts `CrfUsecase` to `apis::crf::CrfService`.

**Tech Stack:** Rust 2024 edition, sqlx 0.9 (postgres, runtime-tokio, macros, migrate, chrono), async-trait, thiserror, chrono, serde, serde_json, PostgreSQL 15+.

## Global Constraints

- **Edition / resolver:** `edition = "2024"`, workspace `resolver = "3"`. The crate's `Cargo.toml` must inherit every shared dep via `{ workspace = true }`.
- **Workspace wiring:** Edit the root `Cargo.toml` once in Task 1 to add `lib/crates/crf` to `[workspace].members`. Edit `lib/crates/apis/src/lib.rs` to expose `pub mod crf;`.
- **SQLx convention:** Use the runtime API (`sqlx::query_as`, `QueryBuilder`). Compile-time-checked macros need a live `DATABASE_URL` or a `sqlx-data.json` cache that the workspace does not currently provide. Document the choice in a module-level comment in each postgres repo file.
- **No `mod.rs`:** every directory uses a sibling file (`src/<name>.rs` + `src/<name>/`) per `docs/guidelines/lib-crate-development.md`.
- **Two-constructor pattern:** every aggregate has a validating `new(...) -> Result<Self, DomainError>` and a `pub(crate) for_repository(...) -> Self`. The latter is reserved for the adapter layer's row bridge; never call it from `usecase`.
- **Errors:** `DomainError` and `UsecaseError` are `#[derive(thiserror::Error)]` enums. Every variant that wraps an inner error carries `#[source] Inner` so the chain is preserved. `UsecaseError::From<DomainError>` maps to `Repository` (because the contract was already broken upstream). Domain validators return `UsecaseError::Validation(...)`.
- **API surface:** the crate root re-exports the documented public surface (aggregates, ports, error enums, command DTOs, view DTOs, concrete repos, the usecase + config, the project-lookup adapter, the facade). Consumers write `use crf::*;` and never reach into sub-modules.
- **Polymorphic annotations:** `crf_annotations` carries four nullable FK columns (`form_id`, `item_id`, `option_id`, `unit_id`) with a CHECK enforcing exactly-one-non-null. The Rust `Annotation` aggregate uses an `AnnotationOwner` enum (`Form(i32) | Item(i32) | Option(i32) | Unit(i32)`) so the polymorphic owner is type-safe at the call site; `Annotation::for_form / for_item / for_option / for_unit` enforce the invariant.
- **Cascade:** every parent FK uses `ON DELETE CASCADE`. `delete_version` removes child forms (and through them, items, options, units, annotations, domain-annotations) via the cascade.
- **Project validation:** `create_version` calls `ProjectLookup::get_by_code` before inserting; returns `UsecaseError::Repository(DomainError::ProjectNotFound(code))` if the project is missing. `update_version` does not re-validate (it does not touch `project_code`).
- **Search:** all six search methods are version-scoped. `fragment` must be non-empty after `trim()` (`UsecaseError::Validation(DomainError::EmptySearchFragment)`). Search uses `ILIKE '%' || $2 || '%'` (no FTS).
- **Kind-shape validation:** `Selection | Checkbox` requires at least one option to exist before the item insert returns; `Text | Datetime | Label` rejects any option on update; `Datetime` allows multiple units.
- **Verification gate (every task that compiles must end green):**

  cargo test -p crf

  ```

  ```

/// Polymorphic owner of an [`AnnotationView`]. Exactly one variant

    Unit { id: i32 },

/// Error surface returned by every [`CrfService`] method. Adapters
/// translate backend-specific errors into this type at the
/// implementation boundary.
#[derive(Debug, Clone, Error)]
pub enum CrfApiError {
    #[error("validation failed: {0}")]
    Validation(String),

    #[error("not found")]
    NotFound,

    #[error("project not found: {0}")]
    ProjectNotFound(String),

    #[error("crf version not found: {0}")]
    CrfVersionNotFound(i32),
    #[error("crf form not found: {0}")]
    CrfFormNotFound(i32),
    #[error("crf item not found: {0}")]
    CrfItemNotFound(i32),
    #[error("crf option not found: {0}")]
    CrfOptionNotFound(i32),
    #[error("crf unit not found: {0}")]
    CrfUnitNotFound(i32),
    #[error("domain annotation not found: {0}")]
    DomainAnnotationNotFound(i32),
    #[error("annotation not found: {0}")]
    AnnotationNotFound(i32),

    #[error("crf version already exists: {project_code} / {name}")]
    DuplicateCrfVersion { project_code: String, name: String },
    #[error("crf form already exists: version {version_id} / {code}")]
    DuplicateCrfForm { version_id: i32, code: String },
    #[error("crf item already exists: form {form_id} / {code}")]
    DuplicateCrfItem { form_id: i32, code: String },
    #[error("domain annotation already exists: form {form_id} / {name}")]
    DuplicateDomainAnnotation { form_id: i32, name: String },

    #[error("referenced crf version not found: {0}")]
    FkCrfVersionNotFound(i32),
    #[error("referenced crf form not found: {0}")]
    FkCrfFormNotFound(i32),
    #[error("referenced crf item not found: {0}")]

    FkCrfOptionNotFound(i32),
    #[error("referenced crf unit not found: {0}")]

}

/// options (Selection / Checkbox) or may carry multiple units
/// (Datetime / Text / Label).

pub enum CrfItemKind {

    Selection,
    Checkbox,
    Datetime,
    Label,
}

impl CrfItemKind {
    /// Canonical SQL string for the kind. Stable; persisted to
    /// `crf_items.kind` and validated by a CHECK constraint.
    pub fn as_str(&self) -> &'static str {
        match self {
            CrfItemKind::Text => "Text",
            CrfItemKind::Selection => "Selection",
            CrfItemKind::Checkbox => "Checkbox",
            CrfItemKind::Datetime => "Datetime",
            CrfItemKind::Label => "Label",
        }
    }
}

impl CrfItemKind {
    /// Parse a SQL string. Inverse of [`Self::as_str`]. Any value
    /// that does not match the canonical set is rejected with
    /// [`DomainError::InvalidCrfItemKind`].
    pub fn try_from_str(s: &str) -> Result<Self, DomainError> {
        match s {
            "Text" => Ok(CrfItemKind::Text),
            "Selection" => Ok(CrfItemKind::Selection),
            "Checkbox" => Ok(CrfItemKind::Checkbox),
            "Datetime" => Ok(CrfItemKind::Datetime),
            "Label" => Ok(CrfItemKind::Label),
            other => Err(DomainError::InvalidCrfItemKind(other.to_string())),
        }
    }
}

use async_trait::async_trait;
use chrono::{DateTime, Utc};

use super::error::DomainError;

/// A Case Report Form version attached to a single project. `id`
/// is the surrogate key; `(project_code, name)` is the natural key
/// the DB enforces via `UNIQUE (project_code, name)`.
#[derive(Clone, PartialEq, Eq)]
pub struct CrfVersion {
    pub id: i32,
    pub project_code: String,
    pub name: String,
    pub created_at: DateTime<Utc>,
    pub updated_at: DateTime<Utc>,
}

impl std::fmt::Debug for CrfVersion {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        f.debug_struct("CrfVersion")
            .field("id", &self.id)
            .field("project_code", &self.project_code)
            .field("name", &self.name)
            .field("created_at", &self.created_at)
            .field("updated_at", &self.updated_at)
            .finish()
    }
}

impl CrfVersion {
    /// Validating constructor used by the domain layer. Rejects
    /// empty / whitespace `project_code` and `name`.
    pub fn new(project_code: String, name: String) -> Result<Self, DomainError> {
        if project_code.trim().is_empty() {
            return Err(DomainError::EmptyProjectCode);
        }
        if name.trim().is_empty() {
            return Err(DomainError::EmptyName);
        }
        Ok(Self {
            id: 0,
            project_code,
            name,
            created_at: DateTime::<Utc>::from_timestamp(0, 0).unwrap(),
            updated_at: DateTime::<Utc>::from_timestamp(0, 0).unwrap(),
        })
    }

    /// Bypasses validation. Reserved for the adapter layer when
    /// materialising rows from persistence.
    pub(crate) fn for_repository(
        id: i32,
        project_code: String,
        name: String,
        created_at: DateTime<Utc>,
        updated_at: DateTime<Utc>,
    ) -> Self {
        Self {
            id,
            project_code,
            name,
            created_at,
            updated_at,
        }
    }
}

/// Input DTO for `CrfVersionRepository::create`.
#[derive(Debug, Clone)]
pub struct CrfVersionNew {
    pub project_code: String,
    pub name: String,
}

/// Input DTO for `CrfVersionRepository::update`. Only `name` is
/// mutable on a version; `id` identifies the row. `project_code`
/// is immutable: changing the owning project would orphan the
/// `crf_forms.version_id` cascade chain.
#[derive(Debug, Clone, Default)]
pub struct CrfVersionUpdate {
    pub id: i32,
    pub name: Option<String>,
}

/// Repository port for `CrfVersion`. Object-safe (`Send + Sync`,
/// no generics in return position beyond `&self`).
#[async_trait]
pub trait CrfVersionRepository: Send + Sync {
    async fn create(&self, input: CrfVersionNew) -> Result<CrfVersion, DomainError>;
    async fn find_by_id(&self, id: i32) -> Result<CrfVersion, DomainError>;
    async fn list_by_project(
        &self,
        project_code: &str,
    ) -> Result<Vec<CrfVersion>, DomainError>;
    async fn update(&self, input: CrfVersionUpdate) -> Result<CrfVersion, DomainError>;
    async fn delete(&self, id: i32) -> Result<(), DomainError>;
}

/// exactly one form, item, option, or unit. The DB CHECK
/// constraint on `crf_annotations` enforces the polymorphic
/// invariant; these constructors enforce it on the Rust side.
#[derive(Clone, PartialEq, Eq)]

    pub id: i32,
    pub domain_annotation_id: i32,
    pub content: String,
    pub assign: bool,
    pub owner: AnnotationOwner,
    pub created_at: DateTime<Utc>,
    pub updated_at: DateTime<Utc>,

            .field("assign", &self.assign)
            .field("owner", &self.owner)
            .field("created_at", &self.created_at)
            .field("updated_at", &self.updated_at)

use thiserror::Error;

use crate::domain::DomainError;

/// Two-variant boundary error between the domain layer and the
/// adapter / facade layer. Mirrors `domain_model::UsecaseError`.
/// `Validation` wraps domain validation errors; `Repository` wraps
/// every other domain error (NotFound, Duplicate*, FK*, etc).
#[derive(Debug, Clone, Error)]
pub enum UsecaseError {
    #[error("validation failed: {0}")]
    Validation(#[source] DomainError),

    #[error("repository error: {0}")]
    Repository(#[source] DomainError),
}

/// Maps every domain error into the appropriate `UsecaseError`
/// variant. Per the project convention, domain validation
/// variants also map to `Repository` (because the contract was
/// already broken upstream) — this impl is the single place that
/// captures that rule. Tests pin the mapping for both
/// validation and runtime variants.
impl From<DomainError> for UsecaseError {
    fn from(err: DomainError) -> Self {
        match err {
            // validation variants
            DomainError::EmptyProjectCode
            | DomainError::EmptyName
            | DomainError::EmptyCode
            | DomainError::EmptyValue
            | DomainError::EmptyContent
            | DomainError::InvalidCrfItemKind(_)
            | DomainError::KindShapeViolation { .. } => UsecaseError::Repository(err),
            // everything else
            other => UsecaseError::Repository(other),
        }
    }
}

/// port. The constructor shape mirrors `DomainModelUsecaseConfig`.
pub struct CrfUsecaseConfig<

    F: CrfFormRepository,
    I: CrfItemRepository,

    Da: DomainAnnotationRepository,

/// Async orchestration for CRF lifecycle operations. Generic over
/// the seven repository ports + the project lookup so tests can
/// inject in-memory fakes. Domain → view projection runs through
/// the `From` impls in `super::views`.
pub struct CrfUsecase<
    V: CrfVersionRepository,
    F: CrfFormRepository,
    I: CrfItemRepository,
    O: CrfOptionRepository,
    U: CrfUnitRepository,
    Da: DomainAnnotationRepository,
    A: AnnotationRepository,
    P: ProjectLookup,
> {
    version_repo: V,
    form_repo: F,
    item_repo: I,
    option_repo: O,
    unit_repo: U,
    domain_annotation_repo: Da,
    annotation_repo: A,
    projects: Arc<P>,
}

impl<V, F, I, O, U, Da, A, P> CrfUsecase<V, F, I, O, U, Da, A, P>
where
    V: CrfVersionRepository,
    F: CrfFormRepository,
    I: CrfItemRepository,
    O: CrfOptionRepository,
    U: CrfUnitRepository,
    Da: DomainAnnotationRepository,
    A: AnnotationRepository,
    P: ProjectLookup,
{
    pub fn new(cfg: CrfUsecaseConfig<V, F, I, O, U, Da, A, P>) -> Self {
        Self {
            version_repo: cfg.version_repo,
            form_repo: cfg.form_repo,
            item_repo: cfg.item_repo,
            option_repo: cfg.option_repo,
            unit_repo: cfg.unit_repo,
            domain_annotation_repo: cfg.domain_annotation_repo,
            annotation_repo: cfg.annotation_repo,
            projects: cfg.projects,
        }
    }

    // ---- CrfVersion ----

    pub async fn create_version(
        &self,
        cmd: CreateCrfVersion,
    ) -> Result<CrfVersionView, UsecaseError> {
        // 1. Reject empty inputs before talking to the project
        //    service or the repo.
        if cmd.project_code.trim().is_empty() {
            return Err(UsecaseError::Repository(DomainError::EmptyProjectCode));
        }
        if cmd.name.trim().is_empty() {
            return Err(UsecaseError::Repository(DomainError::EmptyName));
        }
        // 2. Validate the project exists.
        self.projects.get_by_code(&cmd.project_code).await?;
        // 3. Insert.
        let v = self
            .version_repo
            .create(crate::domain::CrfVersionNew {
                project_code: cmd.project_code,
                name: cmd.name,
            })
            .await?;
        Ok(v.into())
    }

    pub async fn get_version_by_id(&self, id: i32) -> Result<CrfVersionView, UsecaseError> {
        let v = self.version_repo.find_by_id(id).await?;
        Ok(v.into())
    }

    pub async fn list_versions_by_project(
        &self,
        project_code: &str,
    ) -> Result<Vec<CrfVersionView>, UsecaseError> {
        let vs = self.version_repo.list_by_project(project_code).await?;
        Ok(vs.into_iter().map(Into::into).collect())
    }

    pub async fn update_version(
        &self,
        cmd: UpdateCrfVersion,
    ) -> Result<CrfVersionView, UsecaseError> {
        if let Some(ref n) = cmd.name
            && n.trim().is_empty()
        {
            return Err(UsecaseError::Repository(DomainError::EmptyName));
        }
        let v = self
            .version_repo
            .update(crate::domain::CrfVersionUpdate { id: cmd.id, name: cmd.name })
            .await?;
        Ok(v.into())
    }

    pub async fn delete_version(&self, id: i32) -> Result<(), UsecaseError> {
        self.version_repo.delete(id).await?;
        Ok(())
    }
}

        if let Some(o) = input.order { it.order = o; }
        if let Some(ns) = input.not_submitted { it.not_submitted = ns; }

        Ok(it.clone())
    }
    async fn delete(&self, id: i32) -> Result<(), DomainError> {
        let mut rows = self.rows.lock().unwrap();
        let pos = rows.iter().position(|i| i.id == id).ok_or(DomainError::CrfItemNotFound(id))?;
        rows.remove(pos);
        Ok(())
    }

            std::collections::HashMap::new();

            options_by_item.insert(*id, opts.into_iter().map(Into::into).collect());

        // Units (multi-row per item is allowed; the tree loader
        // does NOT de-dupe).
        let mut units_by_item: std::collections::HashMap<i32, Vec<super::views::CrfUnitView>> =

#[derive(FromRow)]
struct CrfVersionRow {
    id: i32,
    project_code: String,
    name: String,
    created_at: DateTime<Utc>,
    updated_at: DateTime<Utc>,
}

impl From<CrfVersionRow> for CrfVersion {

        CrfVersion::for_repository(r.id, r.project_code, r.name, r.created_at, r.updated_at)
    }
}

#[derive(Clone)]
pub struct CrfVersionRepoPg {
    pool: PgPool,
}

impl CrfVersionRepoPg {
    pub fn new(pool: PgPool) -> Self { Self { pool } }
}

#[async_trait]
impl CrfVersionRepository for CrfVersionRepoPg {
    async fn create(&self, input: CrfVersionNew) -> Result<CrfVersion, DomainError> {
        let row: CrfVersionRow = sqlx::query_as::<_, CrfVersionRow>(
            "INSERT INTO crf_versions (project_code, name) VALUES ($1, $2)
             RETURNING id, project_code, name, created_at, updated_at",
        )
        .bind(&input.project_code)
        .bind(&input.name)
        .fetch_one(&self.pool)
        .await
        .map_err(map_db_err)?;
        Ok(row.into())
    }

    async fn find_by_id(&self, id: i32) -> Result<CrfVersion, DomainError> {
        let row: CrfVersionRow = sqlx::query_as::<_, CrfVersionRow>(
            "SELECT id, project_code, name, created_at, updated_at
             FROM crf_versions WHERE id = $1",
        )
        .bind(id)
        .fetch_optional(&self.pool)
        .await
        .map_err(map_db_err)?
        .ok_or(DomainError::CrfVersionNotFound(id))?;
        Ok(row.into())
    }

    async fn list_by_project(&self, project_code: &str) -> Result<Vec<CrfVersion>, DomainError> {
        let rows = sqlx::query_as::<_, CrfVersionRow>(
            "SELECT id, project_code, name, created_at, updated_at
             FROM crf_versions WHERE project_code = $1 ORDER BY id ASC",
        )
        .bind(project_code)
        .fetch_all(&self.pool)
        .await
        .map_err(map_db_err)?;
        Ok(rows.into_iter().map(Into::into).collect())
    }

    async fn update(&self, input: CrfVersionUpdate) -> Result<CrfVersion, DomainError> {
        let row: CrfVersionRow = sqlx::query_as::<_, CrfVersionRow>(
            "UPDATE crf_versions SET name = COALESCE($2, name)
             WHERE id = $1
             RETURNING id, project_code, name, created_at, updated_at",
        )
        .bind(input.id)
        .bind(input.name.as_deref())
        .fetch_optional(&self.pool)
        .await
        .map_err(map_db_err)?
        .ok_or(DomainError::CrfVersionNotFound(input.id))?;
        Ok(row.into())
    }

    async fn delete(&self, id: i32) -> Result<(), DomainError> {
        let res = sqlx::query("DELETE FROM crf_versions WHERE id = $1")
            .bind(id)
            .execute(&self.pool)
            .await
            .map_err(map_db_err)?;
        if res.rows_affected() == 0 {
            return Err(DomainError::CrfVersionNotFound(id));
        }
        Ok(())
    }

fn map_db_err(err: sqlx::Error) -> DomainError {
    use sqlx::Error as E;
    match &err {
        E::Database(db) => {
            if db.code().as_deref() == Some("23505") {
                return DomainError::DuplicateCrfVersion {
                    project_code: "(unknown)".into(),
                    name: "(unknown)".into(),
                };
            }
            if let Some(c) = db.constraint() {
                if c.contains("crf_versions_project_name") {
                    return DomainError::DuplicateCrfVersion {
                        project_code: "(unknown)".into(),
                        name: "(unknown)".into(),
                    };
                }
            }
            DomainError::Repository(err.to_string())
        }
        E::RowNotFound => DomainError::NotFound,
        _ => DomainError::Repository(err.to_string()),
    }
}

                name          = COALESCE($3, name),
                \"order\"       = COALESCE($4, \"order\"),
                not_submitted = COALESCE($5, not_submitted)

            .execute(&self.pool)
            .await
            .map_err(map_db_err)?;
        if res.rows_affected() == 0 {
            return Err(DomainError::CrfItemNotFound(id));
        }
        Ok(())
    }

    async fn search_by_version(&self, version_id: i32, fragment: &str) -> Result<Vec<CrfItem>, DomainError> {

            "SELECT i.id, i.form_id, i.code, i.name, i.kind, i.\"order\", i.not_submitted, i.created_at, i.updated_at
             FROM crf_items i
             JOIN crf_forms f ON f.id = i.form_id
             WHERE f.version_id = $1 AND (i.code ILIKE $2 OR i.name ILIKE $2)
             ORDER BY i.\"order\" ASC, i.id ASC",
        )
        .bind(version_id)
        .bind(&pat)
        .fetch_all(&self.pool)
        .await
        .map_err(map_db_err)?;
        Ok(rows.into_iter().map(Into::into).collect())
    }

fn map_db_err(err: sqlx::Error) -> DomainError {
    use sqlx::Error as E;
    match &err {
        E::Database(db) => {
            if db.code().as_deref() == Some("23505") {
                return DomainError::DuplicateCrfItem { form_id: 0, code: "(unknown)".into() };
            }
            if let Some(c) = db.constraint() {
                if c.contains("crf_items_form_code") {
                    return DomainError::DuplicateCrfItem { form_id: 0, code: "(unknown)".into() };
                }
            }
            DomainError::Repository(err.to_string())
        }
        E::RowNotFound => DomainError::NotFound,
        _ => DomainError::Repository(err.to_string()),
    }
}
