# `SdtmDomainList` Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the first page of the `domain-model` feature: a read/delete list of SDTM domains at `/domain-model/sdtm`, with client-side text filtering, version dropdown, and a per-page language dropdown that switches Description / Structure columns.

**Architecture:** Mirror the existing `terminology` feature end-to-end. Backend adds `http/domain_model/{version,domain}.rs` plus `commands/domain_model/{version,domain}.rs`, with shared `DomainCategory` enum in `http/dto.rs`. Frontend adds `features/domain-model/{pages,components,data}/` with the same TanStack Query / MUI / Testing Library pattern. The list endpoint returns the whole list (not paginated) so a simple `useQuery` replaces the infinite query used by terminology.

**Tech Stack:** Tauri 2, Rust 2021, wiremock (Rust tests), React 19, @tanstack/react-router 1, @tanstack/react-query 5, MUI 5, Vitest 2, Testing Library.

**Spec:** [docs/superpowers/specs/2026-08-25-aegis-desktop-domain-model-sdtm-domain-list-design.md](../specs/2026-08-25-aegis-desktop-domain-model-sdtm-domain-list-design.md)

## Global Constraints

These rules apply to every task:

- Follow the existing `http/terminology/` and `commands/terminology/` patterns 1:1 — module names, file layout, serde `rename_all`, test style. Read both before starting.
- Tauri HTTP DTOs use `#[serde(rename_all = "camelCase")]` (matches existing `UserViewResponse` convention). The shared `DomainCategory` enum lives in `http/dto.rs` with `#[serde(rename = "Special Purpose")]` per variant, parallel to `TerminologyKind`.
- The frontend types mirror the wire shape (snake_case → camelCase). `id: i64` on Rust → `id: number` on TS.
- Mutation buttons render only when `currentUser.data?.role === "admin" || role === "root"`; the server's `require_admin_or_root` is the final word.
- Bilingual i18n: `TranslationKey` is derived from `typeof en` in `lib/packages/ui/src/i18n/types.ts`. **Every new translation key must be added to BOTH `en.ts` and `zhCN.ts` in the same commit, otherwise TypeScript fails to compile.** The user explicitly opted to ship English-only with English placeholder values in `zhCN.ts`; the tree stays in place for follow-up translations.
- Route file generation: `apps/desktop/aegis-desktop/src/routes/routeTree.gen.ts` is auto-generated by `@tanstack/router-plugin`. Never hand-edit it. `pnpm build` regenerates it.
- Component tests live alongside components (`*.test.tsx` next to the file); page tests live alongside the page (`SdtmDomainList.test.tsx` next to `SdtmDomainList.tsx`).
- Mutation invalidation: `useDeleteSdtmDomain`'s 204 does not echo `versionId`, so on success we invalidate `["domainModel", "sdtmDomains"]` broadly.
- Commit message prefix `feat(domain-model):` for new behavior, `test(domain-model):` for tests, `docs(domain-model):` for docs, `chore(domain-model):` for housekeeping, `fix(domain-model):` for fixes.
- All work happens on the current branch (`feat/desktop_sdtm-list`).

```rust
//! Versions under `/api/domain-model/versions`.

use chrono::{DateTime, Utc};
use serde::{Deserialize, Serialize};

use crate::http::client::HttpClient;
use crate::http::dto::ApiError;

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct SdtmVersionViewResponse {
    pub id: i64,
    pub name: String,
    pub created_at: DateTime<Utc>,
    pub updated_at: DateTime<Utc>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct SdtmVersionListResponse {
    pub versions: Vec<SdtmVersionViewResponse>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct CreateSdtmVersionRequest {
    pub name: String,
}

#[derive(Debug, Default, Clone, Serialize, Deserialize)]
#[serde(rename_all = "camelCase")]
pub struct UpdateSdtmVersionRequest {
    #[serde(skip_serializing_if = "Option::is_none")]
    pub name: Option<String>,
}

pub async fn create(
    c: &HttpClient,
    body: CreateSdtmVersionRequest,
) -> Result<SdtmVersionViewResponse, ApiError> {
    c.request(reqwest::Method::POST, "/api/domain-model/versions", Some(&body))
        .await
}

pub async fn list(c: &HttpClient) -> Result<Vec<SdtmVersionViewResponse>, ApiError> {
    let resp: SdtmVersionListResponse = c
        .request(reqwest::Method::GET, "/api/domain-model/versions", None::<&()>)
        .await?;
    Ok(resp.versions)
}

pub async fn get_by_id(
    c: &HttpClient,
    id: i64,
) -> Result<SdtmVersionViewResponse, ApiError> {
    c.request(
        reqwest::Method::GET,
        &format!("/api/domain-model/versions/{id}"),
        None::<&()>,
    )
    .await
}

pub async fn update(
    c: &HttpClient,
    id: i64,
    body: UpdateSdtmVersionRequest,
) -> Result<SdtmVersionViewResponse, ApiError> {
    c.request(
        reqwest::Method::PUT,
        &format!("/api/domain-model/versions/{id}"),
        Some(&body),
    )
    .await
}

pub async fn delete(c: &HttpClient, id: i64) -> Result<(), ApiError> {
    let _ = c
        .request_bytes(
            reqwest::Method::DELETE,
            &format!("/api/domain-model/versions/{id}"),
            None::<&()>,
        )
        .await?;
    Ok(())
}
```

## Task 20: `pages/SdtmDomainList.tsx`

**Files:**
- Create: `apps/desktop/aegis-desktop/src/features/domain-model/pages/SdtmDomainList.tsx`

**Interfaces:**
- Page component. Owns URL-driven `versionId`, `lang` (both round-tripped as number-or-string by the route's `validateSearch`); local `searchFragment` and `confirmDelete` state. Derives `availableLanguages` from loaded data. Filters rows client-side. Uses the 4 components.

- [ ] **Step 1: Implement `SdtmDomainList.tsx`**

```tsx
import { useEffect, useMemo, useState } from "react";
import { Box, Typography } from "@aegis/ui/mui";
import { useNavigate, useSearch } from "@tanstack/react-router";
import { useI18n } from "@aegis/ui/i18n";

import { useDebouncedValue } from "../../../shared/hooks/useDebouncedValue";
import { useCurrentUser } from "../../auth";
import {
  useDeleteSdtmDomain,
  useListSdtmDomains,
  useListSdtmVersions,
} from "../data";
import type { SdtmDomainView } from "../../../shared/api";
import {
  DeleteDomainDialog,
  DomainFilterBar,
  DomainTable,
  LanguageDropdown,
  VersionDropdown,
} from "../components";

export function SdtmDomainList() {
  const { t } = useI18n();
  const navigate = useNavigate();
  const currentUser = useCurrentUser();
  const versionsQuery = useListSdtmVersions();

  const routeSearch = useSearch({ strict: false }) as {
    versionId?: number;
    lang?: string;
  };
  const urlVersionId = routeSearch.versionId;
  const urlLang = routeSearch.lang;

  const [searchFragment, setSearchFragment] = useState("");
  const [confirmDelete, setConfirmDelete] = useState<SdtmDomainView | null>(null);

  const versions = versionsQuery.data ?? [];

  const selectedVersionId = useMemo<number | null>(() => {
    if (urlVersionId != null && versions.some((v) => v.id === urlVersionId)) {
      return urlVersionId;
    }
    return versions[0]?.id ?? null;
  }, [urlVersionId, versions]);

  useEffect(() => {
    if (versions.length === 0) return;
    const urlIsValid =
      urlVersionId != null && versions.some((v) => v.id === urlVersionId);
    if (urlIsValid) return;
    const fallback = versions[0].id;
    void navigate({
      to: "/domain-model/sdtm",
      replace: true,
      search: (prev) => ({
        ...prev,
        versionId: fallback,
      }),
    });
  }, [urlVersionId, versions, navigate]);

  const setSelectedVersionId = (id: number | null) => {
    void navigate({
      to: "/domain-model/sdtm",
      search: (prev) => ({
        ...prev,
        versionId: id ?? undefined,
        lang: undefined,
      }),
    });
  };

  const domainsQuery = useListSdtmDomains(selectedVersionId);

  const allDomains = domainsQuery.data ?? [];
  const availableLanguages = useMemo(() => {
    const set = new Set<string>();
    for (const d of allDomains) {
      for (const desc of d.descriptions) set.add(desc.lang);
    }
    return [...set].sort();
  }, [allDomains]);

  const selectedLang = useMemo<string | null>(() => {
    if (urlLang && availableLanguages.includes(urlLang)) return urlLang;
    return availableLanguages[0] ?? null;
  }, [urlLang, availableLanguages]);

  useEffect(() => {
    if (availableLanguages.length === 0) return;
    const urlIsValid = urlLang != null && availableLanguages.includes(urlLang);
    if (urlIsValid) return;
    const fallback = availableLanguages[0];
    void navigate({
      to: "/domain-model/sdtm",
      replace: true,
      search: (prev) => ({ ...prev, lang: fallback }),
    });
  }, [urlLang, availableLanguages, navigate]);

  const setSelectedLang = (lang: string | null) => {
    void navigate({
      to: "/domain-model/sdtm",
      search: (prev) => ({ ...prev, lang: lang ?? undefined }),
    });
  };

  const debouncedFragment = useDebouncedValue(searchFragment, {
    delayMs: 300,
    maxWaitMs: 1000,
  });

  const trimmedFragment = debouncedFragment.trim().toLowerCase();
  const filteredRows = useMemo(() => {
    if (!trimmedFragment) return allDomains;
    return allDomains.filter((row) => {
      if (row.name.toLowerCase().includes(trimmedFragment)) return true;
      return row.descriptions.some(
        (d) =>
          d.details.description.toLowerCase().includes(trimmedFragment) ||
          d.details.structure.toLowerCase().includes(trimmedFragment),
      );
    });
  }, [allDomains, trimmedFragment]);

  const deleteDomain = useDeleteSdtmDomain();
  const role = currentUser.data?.role;
  const canMutate = role === "admin" || role === "root";

  const noVersions = !versionsQuery.isLoading && versions.length === 0;

  return (
    <Box sx={{ p: 4, display: "flex", flexDirection: "column", gap: 2 }}>
      <Typography variant="h4">
        {t("domainModel.sdtm.heading")}
      </Typography>

      {noVersions ? (
        <Typography color="text.secondary">
          {t("domainModel.sdtm.noVersions")}
        </Typography>
      ) : (
        <>
          <Box
            sx={{
              display: "flex",
              gap: 2,
              alignItems: "center",
              flexWrap: "wrap",
            }}
          >
            <DomainFilterBar
              query={searchFragment}
              onQueryChange={setSearchFragment}
            />
            <VersionDropdown
              versions={versions}
              value={selectedVersionId}
              onChange={setSelectedVersionId}
            />
            <LanguageDropdown
              options={availableLanguages}
              value={selectedLang}
              onChange={setSelectedLang}
            />
          </Box>

          <DomainTable
            rows={filteredRows}
            loading={domainsQuery.isLoading}
            error={domainsQuery.error}
            canMutate={canMutate}
            selectedLang={selectedLang}
            onRetry={() => domainsQuery.refetch()}
            onDelete={(row) => setConfirmDelete(row)}
            emptyMessage={
              trimmedFragment
                ? t("domainModel.sdtm.noMatches")
                : t("domainModel.sdtm.empty")
            }
          />
        </>
      )}

      <DeleteDomainDialog
        open={confirmDelete !== null}
        row={confirmDelete}
        onClose={() => setConfirmDelete(null)}
        onConfirm={(row) =>
          deleteDomain.mutate(row.id, {
            onSuccess: () => setConfirmDelete(null),
          })
        }
        pending={deleteDomain.isPending}
        error={deleteDomain.error}
      />
    </Box>
  );
}
```
