# Aegis Desktop — Metadata Page — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `/metadata` page that surfaces navigation to the existing SDTM and ADaM terminology pages, plus a new `Knowledge Base` sidebar entry that links to it.

**Architecture:** A pure presentational page with two MUI `Card`s (SDTM, ADaM) containing a disabled `Domain Model` row and a `Terminology` row that navigates to the existing `/terminology/{sdtm,adam}` routes. The existing sidebar `AppLayout` gains a `Knowledge Base` entry with a `Metadata` sub-menu. No new server endpoints, no new React Query hooks, no new shared API types.

**Tech Stack:** React 19, TanStack Router (file-based routes), Material UI, `@aegis/ui/i18n` bilingual catalog (`en`, `zh-CN`), Vitest + Testing Library.

---

## Global Constraints

These rules apply to every task:

- **Bilingual i18n:** `TranslationKey` is derived from `typeof en` in `lib/packages/ui/src/i18n/types.ts`. **Every new translation key must be added to BOTH `en.ts` and `zhCN.ts` in the same commit, otherwise TypeScript fails to compile.**
- **Bilingual translations, exact match required:** en/zh-CN strings are user-visible copy. Keep en short and use the existing zh-CN conventions from neighbouring keys (e.g. `术语` for Terminology, `元数据` for Metadata).
- **Route file generation:** `apps/desktop/aegis-desktop/src/routes/routeTree.gen.ts` is auto-generated by `@tanstack/router-plugin`. **Never hand-edit it.** Re-run the dev server or `pnpm tauri dev` (which triggers the codegen) before relying on its content.
- **Sidebar pattern:** A parent menu entry with `subMenu` uses a placeholder `link` (e.g. `#metadata`) and clicking the label only toggles the submenu open/closed. The sub-menu items do the navigation. Match this for `Knowledge Base` exactly.
- **TDD for page tests:** Tests live under `apps/desktop/aegis-desktop/src/test/features/metadata/pages/` (matching `apps/desktop/aegis-desktop/src/test/features/settings/pages/`). They use `renderInRouter` + `AegisI18nProvider` + `AegisThemeProvider`.
- **Mock `useNavigate`:** Do **not** mock `useNavigate`. Use `renderInRouter` (returns the router) and assert on `router.state.location.pathname` after click — the same pattern used by `login-route.test.tsx`.

```tsx
import { useNavigate } from "@tanstack/react-router";
import {
  Box,
  Card,
  CardHeader,
  List,
  ListItem,
  ListItemButton,
  ListItemIcon,
  ListItemText,
  Tooltip,
  Typography,
} from "@aegis/ui/mui";
import { useI18n } from "@aegis/ui/i18n";
import {
  Analytics as AnalyticsIcon,
  Architecture as ArchitectureIcon,
  Storage as StorageIcon,
} from "@aegis/ui/icons";

// Kinds shown on the page. Ordering is significant: index 0 is rendered
// in the left card, index 1 in the right card.
const KINDS = ["sdtm", "adam"] as const;
type Kind = (typeof KINDS)[number];

interface BlockSpec {
  kind: Kind;
  blockKey: "metadata.block.sdtm" | "metadata.block.adam";
  terminologyTarget: "/terminology/sdtm" | "/terminology/adam";
  terminologyIcon: typeof StorageIcon;
}

const BLOCKS: BlockSpec[] = [
  {
    kind: "sdtm",
    blockKey: "metadata.block.sdtm",
    terminologyTarget: "/terminology/sdtm",
    terminologyIcon: StorageIcon,
  },
  {
    kind: "adam",
    blockKey: "metadata.block.adam",
    terminologyTarget: "/terminology/adam",
    terminologyIcon: AnalyticsIcon,
  },
];

export function MetadataPage() {
  const { t } = useI18n();
  const navigate = useNavigate();

  return (
    <Box sx={{ p: 4, display: "flex", flexDirection: "column", gap: 3 }}>
      <Typography variant="h4">{t("metadata.heading")}</Typography>

      <Box sx={{ display: "flex", gap: 3, flexWrap: "wrap" }}>
        {BLOCKS.map((block) => (
          <Card key={block.kind} sx={{ flex: 1, minWidth: 320 }}>
            <CardHeader title={t(block.blockKey)} />
            <List disablePadding>
              <ListItem disablePadding>
                <Tooltip title={t("metadata.disabled.tooltip")}>
                  {/* span wrapper so Tooltip can attach to a disabled button */}
                  <span style={{ width: "100%" }}>
                    <ListItemButton disabled>
                      <ListItemIcon>
                        <ArchitectureIcon />
                      </ListItemIcon>
                      <ListItemText primary={t("metadata.item.domainModel")} />
                    </ListItemButton>
                  </span>
                </Tooltip>
              </ListItem>
              <ListItem disablePadding>
                <ListItemButton
                  onClick={() => navigate({ to: block.terminologyTarget })}
                >
                  <ListItemIcon>
                    <block.terminologyIcon />
                  </ListItemIcon>
                  <ListItemText primary={t("metadata.item.terminology")} />
                </ListItemButton>
              </ListItem>
            </List>
          </Card>
        ))}
      </Box>
    </Box>
  );
}
```
